隐私政策

最后更新日期：2026年8月24日

我们深知个人信息对您的重要性，将以最大诚意和审慎态度保护您的隐私。本政策详细说明我们如何收集、使用、存储和保护您的个人信息。

一、我们收集的信息

1. 您主动提供的信息

- 注册 LaswI ID 时：用户名、手机号或邮箱（用于注册和登录验证）。

- 创建智能体时：智能体名称、描述、人设提示词、选择的工具。

- 使用 AI 对话时：您输入的文字内容和语音转写文本。

- 使用备忘录时：您创建的备忘内容。

2. 自动收集的信息

- 设备信息：设备型号、操作系统版本、屏幕尺寸、唯一设备标识符。

- 使用日志：启动时间、页面访问记录、功能使用频率、崩溃日志。

- 位置信息：仅在使用天气和地图功能时，通过您授权获取的大致位置或您输入的城市名称。我们不持续追踪您的位置。

3. 第三方服务收集的信息

- 智谱 AI（GLM-4/CogView）：您与 AI 的对话内容和生图请求会发送至智谱服务器进行处理。

- 高德地图：天气查询和地图服务由高德提供，您的查询关键词会发送至高德服务器。

- Supabase（如已配置）：用户注册数据和智能体数据存储在 Supabase 云端数据库。

二、我们如何使用信息

1. 提供核心服务：AI 对话、智能体管理、天气地图等功能的正常运行。

2. 改善服务质量：分析使用数据优化产品体验、修复 Bug、提升 AI 回复质量。

3. 个性化体验：记住您的偏好设置、对话历史、收藏的智能体。

4. 账号安全：验证身份、检测异常登录、防范欺诈和滥用。

5. 服务通知：向您发送重要通知（如服务变更、安全提醒）。

6. 法律合规：配合法律法规要求，在必要时向有权机关提供相关信息。

三、信息存储与保护

1. 存储方式

- 本地存储：对话历史、备忘录内容、偏好设置等存储在您设备的本地存储中。清除应用数据或更换设备将导致这些数据丢失。

- 云端存储：注册用户的基本信息、创建的智能体数据存储在 Supabase 云端（如您已配置）。

- 对话内容发送至智谱 AI 进行处理，智谱 AI 的数据存储政策详见其隐私政策。

2. 保护措施

- 数据传输采用 HTTPS 加密。

- API Key 等敏感信息存储在应用内部，不对用户展示。

- 我们对员工访问权限进行严格管理，仅授权人员可接触用户数据。

- 尽管我们采取合理措施保护您的信息，但互联网传输和电子存储不存在绝对安全的方式，我们无法保证 100% 安全。
